🐧 Ubuntu / Debian

Ubuntu 18.04 atau lebih baru, 64-bit

Download .deb (x86_64)–
Cara install
  1. Buka Terminal di folder download.
  2. Jalankan sudo apt install ./GudDesk-linux-amd64.deb
  3. Buka aplikasi RustDesk dari menu aplikasi.

🍎 macOS

Apple Silicon: macOS 12.3+ · Intel: macOS 10.14+

Apple Silicon (M1/M2/M3/M4)– Intel–
Cara install
  1. Buka file .dmg, seret ikon ke folder Applications.
  2. Karena aplikasi belum di-notarize Apple, buka Terminal lalu jalankan:
    xattr -cr /Applications/RustDesk.app
  3. Buka aplikasinya, lalu izinkan Screen Recording dan Accessibility di System Settings → Privacy & Security.

🤖 Android

Android 6.0 atau lebih baru

HP modern (arm64)– HP lama (armv7)–
Cara install
  1. Download APK (hampir semua HP sekarang pakai arm64).
  2. Buka file-nya, izinkan Install dari sumber tidak dikenal kalau diminta.
  3. Untuk dikontrol dari PC: buka tab Share Screen, lalu aktifkan service dan izinnya.

Cara pakai

Buka aplikasi di kedua perangkat. Perangkat yang mau diremote memberikan ID dan password yang tampil di layar, lalu perangkat yang mengontrol memasukkan ID itu di kolom Control Remote Desktop. Status Ready di bagian bawah aplikasi berarti sudah tersambung ke server GudDesk.

Pakai aplikasi RustDesk resmi? Isi server manual

Hanya perlu kalau kamu install RustDesk dari situs/Play Store resmi (misalnya untuk Windows atau iOS). Buka Settings → Network → ID/Relay server.
